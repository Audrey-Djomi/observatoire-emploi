# Projet: Observatoire des métiers et de l'emploi

Ce projet a pour objectif de construire un observatoire des métiers et de l'emploi en France à partir de données publiques.

L'objectif étant d'analyser le marché du travail afin d'identifier :
- les métiers les plus recherchés,
- les compétences les plus demandées,
- les secteurs d'activité qui recrutent,
- les territoires présentatnt une dynamique particulière,
- les difficultés et tensions de recrutement,
- les évolutions du marché du travail dans le temps.

Le projet est réalisé progressivement dans une démarche Data Analytics, depuis la collecte et la préparation des données jusqu'à leur analyse et leur visualisation.

## Objectifs

Le projet cherchera notamment à répondre aux questions suivantes:
 1. Quels sont les métiers les plus recherchés ?
 2. Quelles compétences sont les plus demandées ?
 3. Quels secteurs recructent le plus ?
 4. Quels territoires présentent le plus d'opportunités ?
 5. Quels métiers connaissent des difficultés de recrutement ?
 6. Comment évoluent la demande selon les métiers et les périodes ?
 7. Quels indicateurs peuvent aider à mieux comprendre les tendances du marché de l'emploi ? 

 ## Méthodologie

 Notre projet suivra plusieurs étapes:

 - Collecte
 - Exploration
 - Nettoyage
 - Transformation
 - Analyse
 - Visualisation
 - Documentation

 Les données brutes seront conservées séparément des données néttoyées afin de préserver la traçabilité des traitements réalisés.

 ## Technologies envisagées

 - Python
 - Pandas
 - Numpy
 - requests
 - SQL
 - Power BI
 - Git/Github

 Les outils pourront évoluer au cours du projet selon les besoins d'analyses.

 ## Sources des données

Les données utilisées proviendront de sources publiques et officielles, notamment les données mises à disposition par France Travail et la DARES.

Les sources et leur documentation seront référencées au fur et à mesure de l'avancement du projet.

## Résultats attendus

Le projet aboutira à une analyse documentée du marché du travail ainsi qu'à un tableau de bord permettant d'explorer les principaux indicateurs liés aux métiers, aux compétences, aux territoires et au recrutement.

## 🚧 Etat du projet

Projet en cours de developpement.
